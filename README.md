# joseantonylopes-source.github.io

`conversor_pecas_markdown.html` — conversor de peças processuais (PDF e HTML) para um único arquivo Markdown, executado inteiramente no navegador. Os HTML gerados pelo editor do e-Proc são reconhecidos pelas classes do próprio documento (timbre, identificação do processo, partes, ementa, assinatura e rodapé).
